Project Name:
MediSync – Smart Hospital Management System

Project Type:
Enterprise Full Stack Web Application

Purpose:
To digitize hospital operations including patient registration,
doctor management, appointments, medical records, billing,
prescriptions, notifications, and analytics.

Target Users:
• Super Admin
• Hospital Admin
• Doctor
• Nurse
• Receptionist
• Patient
Problem Statement

Many hospitals still rely on manual processes for
appointments, billing, and medical records.

Problems include:
• Long waiting times
• Lost medical files
• Scheduling conflicts
• Poor communication
• Billing errors
• Difficult report management

Our system solves these problems by providing
a centralized digital platform.
