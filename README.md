# 🏥 MediSync - Smart Hospital Management System

A modern full-stack Hospital Management System built with React, Node.js, Express, PostgreSQL, and TypeScript.

---

## 📌 Project Overview

MediSync is an enterprise-level Hospital Management System designed to simplify hospital operations such as patient management, appointment booking, medical records, billing, prescriptions, and analytics.

---

## 🚀 Features

### Authentication
- User Login
- User Registration
- JWT Authentication
- Role-Based Access Control (RBAC)

### Patient Management
- Add Patient
- Update Patient
- Delete Patient

### Doctor Management
- Add Doctor
- Manage Departments

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/MediSync-Hospital-Management-System.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
